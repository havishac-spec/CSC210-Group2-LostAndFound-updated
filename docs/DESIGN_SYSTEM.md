# Frontend Design System

## Visual direction
Clean, trustworthy, student-friendly, quick and uncluttered. Avoid making the product look like an e-commerce store.

## Layout
Recommended content max-width: 1200px. Use consistent spacing and reusable components.

## Typography
Modern sans-serif. Hierarchy: page title → section heading → card title → body → secondary text.

## Buttons
Primary: Report Lost, Report Found, Submit, Login.
Secondary: Browse, Cancel, Edit.
Danger: Delete / Report abuse.

## Item cards
Consistently display:
`Image | Type | Title | Category | Location | Date | Status | Action`

## Images
Use a consistent aspect ratio, rounded corners, `object-fit: cover`, and a placeholder when no image exists. Never stretch images.

## Responsive breakpoints
Approximate:
- Mobile `< 768px`
- Tablet `768–1023px`
- Desktop `≥ 1024px`

## UX principle
Every page should make the next action obvious:
`Lost something? → Report Lost`
`Found something? → Report Found`
`Looking for something? → Search`
