# UX Flow

## First-time user
`Login → Sign Up → Dashboard`

## Returning user
`Login → Dashboard`

## Report Lost
`Dashboard → Report Lost → Fill details → Upload image → Review → Submit → Success → Possible matches / My Reports`

## Report Found
`Dashboard → Report Found → Fill details → Upload image → Review → Submit → Success → Browse / Possible matches`

## Find an item
`Dashboard → Search → Apply filters → Results → Item details → Possible match / contact`

## Navigation principle
Users should not have to return to the dashboard just to switch between the core actions. Keep Report Lost, Report Found, Browse and My Reports directly accessible.
